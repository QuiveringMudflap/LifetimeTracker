# Maison Claire — Website

Static one-page site for Maison Claire (Natural Healing • Higher Wellbeing • A Brighter You).

## Files
- `index.html` — page content and structure
- `styles.css` — visual design
- `vercel.json` — Vercel static hosting config

## Editing
- Text (services, taglines, phone, email) lives in `index.html`.
- Colors, fonts, and spacing live at the top of `styles.css` under `:root { ... }`.

## Deployment
Deployed on Vercel from this folder. To publish an edit, commit and push to the
tracked branch — Vercel rebuilds automatically.
